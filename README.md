# AI-OS

一个基于Electron的桌面应用操作系统，允许用户在无限画布上创建和管理应用块，实现多任务并行处理。

## 功能特点

### 🚀 核心功能
- **无限画布**：提供无限大的工作空间，支持自由拖拽和缩放
- **应用块管理**：在画布上创建、移动和调整应用块大小
- **应用启动**：通过应用块快速启动和管理外部应用程序
- **应用预览**：实时预览正在运行的应用程序

### 🎨 交互特性
- **拖拽操作**：通过标题栏拖拽移动应用块
- **大小调整**：通过拖拽边缘调整应用块大小（支持右边缘、下边缘和右下角）
- **智能重置**：应用关闭后自动恢复到初始状态
- **双击启动**：双击应用块快速启动应用

## 技术栈

- **前端框架**：Electron + TypeScript + Vite
- **UI样式**：CSS3 + Flexbox
- **构建工具**：Electron Forge + Vite

## 使用指南

### 1. 创建应用块
- 点击顶部导航栏的"+"按钮
- 在弹出的抽屉中选择要启动的应用
- 点击应用图标即可在画布上创建应用块

### 2. 管理应用块
- **移动**：拖拽应用块标题栏可以移动位置
- **调整大小**：将鼠标悬停在应用块边缘，当光标变为调整大小时拖拽调整
- **关闭应用**：点击应用块右上角的"×"按钮关闭应用

### 3. 画布操作
- **平移**：在画布空白处按住鼠标左键拖拽
- **缩放**：使用鼠标滚轮或触控板手势缩放画布

### 4. 应用管理
- **启动应用**：双击应用块启动对应的应用程序
- **重置应用块**：应用关闭后，应用块会自动恢复到初始状态

## 开发说明

### 主要组件

1. **无限画布** (InfiniteCanvas)
   - 处理画布的拖拽和缩放
   - 管理应用块的容器

2. **应用块** (AppBlock)
   - 表示单个应用的容器
   - 处理应用的启动、关闭和状态管理
   - 支持拖拽和大小调整

3. **应用抽屉** (AppDrawer)
   - 显示可用应用列表
   - 处理应用选择和创建

### 关键功能实现

- **应用启动**：通过Electron的`shell.openPath()`启动外部应用
- **应用预览**：使用`desktopCapturer` API获取应用窗口内容
- **状态管理**：使用Map数据结构管理应用块状态

## 常见问题

### Q: 应用启动失败怎么办？
A: 请检查应用路径是否正确，以及应用是否已正确安装在系统中。

### Q: 如何调整应用块大小？
A: 将鼠标悬停在应用块边缘，当光标变为调整大小时拖拽调整。

### Q: 应用关闭后为什么显示黑屏？
A: 这个问题已在v1.0.0中修复，现在应用关闭后会自动恢复到初始状态。
